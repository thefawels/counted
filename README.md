# Counted!

**Counted!** — PWA для подсчёта остатков и инвентаризации в пиццерии. Работает на телефоне, сохраняет прогресс и помогает выгружать результаты в Excel.

## Что умеет

- **Ревизия:** подсчёт продуктов по каталогу с калькулятором, отдельными блоками подсчёта и экспортом.
- **Перепроверка ревизии:** загрузка отчёта «Потери и избыток» из DodoIS, сверка и повторный пересчёт позиций.
- **Расходники:** подсчёт по выбранной пиццерии и заполнение бланка Excel.
- **Химия:** отдельный пересчёт химии и расходных материалов с сохранением результата.

## Как пользоваться

1. Открой приложение и выбери режим на главном экране.
2. При необходимости загрузи Excel-файл или выбери пиццерию.
3. Считай позиции через калькулятор. Результаты сохраняются по мере работы.
4. По окончании открой **«Итоги»** и экспортируй Excel.

> **Важно:** данные подсчётов хранятся локально в браузере. Перед очисткой данных сайта, переустановкой приложения или сбросом подсчёта выгрузи результат.

## Офлайн-работа

Counted! — статическое веб-приложение (PWA). После первоначальной загрузки и установки офлайн-кеша оно может работать без интернета. Для установки на главный экран открой опубликованное приложение в браузере телефона и используй команду добавления на экран «Домой».

## Файлы проекта

- `index.html` — точка входа.
- `app-counted-v10.js` — основная логика текущей сборки.
- `count-mode-*`, `catalog-v10.js` — режим ревизии.
- `chemistry-*`, `supplies-*` — химия и расходники.
- `base-v091.css`, `count-mode-v10.css` — стили.
- `sw.js`, `manifest.webmanifest` — офлайн-кеш и установка PWA.
- `iconoir.js` — иконки интерфейса.

Проект запускается как статический сайт, без серверной части. Для корректной работы PWA нужен HTTPS или локальный веб-сервер.

Старые сборки удалены из корня репозитория, но доступны в **Git history**. Версия приложения не менялась.
