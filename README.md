# Counted!

**Counted!** — приложение для инвентаризации в пиццерии. Помогает считать продукты и расходные материалы, перепроверять остатки и собирать результат в Excel без бумажных списков.

Это **PWA**: открывается в браузере, устанавливается на главный экран телефона и после загрузки необходимых файлов может работать без интернета.

## Возможности

| Режим | Для чего нужен |
| --- | --- |
| **Ревизия** | Подсчёт продуктов по готовому каталогу с калькулятором и отдельными блоками измерений. |
| **Перепроверка ревизии** | Загрузка отчёта «Потери и избыток» из DodoIS, сверка данных и повторный подсчёт. |
| **Расходники** | Подсчёт упаковки и других расходных материалов для выбранной пиццерии. |
| **Химия** | Учёт чистящих средств и связанных расходных материалов по отдельному списку. |

Также доступны поиск по позициям, сохранение незавершённого подсчёта, калькулятор и экспорт результатов в Excel.

## Как пользоваться

1. Открой опубликованный сайт Counted! или запусти свою копию.
2. Выбери один из четырёх режимов.
3. Если режим требует исходный отчёт, загрузи файл; для расходников и химии выбери пиццерию.
4. Пересчитывай позиции в калькуляторе. Результаты сохраняются на устройстве.
5. Перейди в **«Итоги»** и выгрузи Excel.

> **Важно:** Counted! хранит подсчёты локально в браузере, а не в облаке. Если очистить данные сайта, сменить браузер или удалить приложение, сохранённый прогресс может пропасть. Перед этим обязательно выгружай Excel.

## Для кого подходит

Приложение создавалось для повседневной инвентаризации в пиццерии. Его можно использовать как готовый инструмент или как основу собственного решения.

**Ограничения:** каталоги, шаблоны Excel и список пиццерий частично настроены под конкретный рабочий процесс. Для другой точки или бизнеса их может потребоваться изменить. Режим перепроверки рассчитан на соответствующий формат отчёта DodoIS. Это независимый проект, не официальный продукт Dodo Pizza.

## Запуск и установка

Для использования нужен современный браузер. На iPhone можно добавить открытый сайт на экран «Домой» через меню «Поделиться». При первом запуске нужно подключение к интернету, чтобы загрузить файлы для офлайн-работы.

Чтобы опубликовать свою копию, размести содержимое репозитория на статическом HTTPS-хостинге, например GitHub Pages. Сборка и серверная часть не требуются.
